# DS «Управління домом» — візуальний макет (Етап 1)

Пакет дизайн-системи для радикального редизайну розділу **«Управління домом»** платформи OSBB.
Усе побудовано **строго на існуючих токенах** `app/globals.css` (`--cms-*`, `--r-*`, Inter/Lora), тёмна «золота» тема — основна, світла — перевірочна.

| `TZ_HOUSE_MANAGEMENT_REDESIGN_v2.md` | Уточнене ТЗ (v2) з зафіксованими рішеннями за підсумками ревʼю. |
| `README.md` | Цей файл. |

## Як користуватись макетом

Верхня панель (мета-хром, не частина продукту) перемикає 5 наборів екранів і тему:

- **Shell дому** — Ф2: компактна sticky-шапка, свитчер домів, табова навігація 10 розділів + overflow «Ще ▾» + пін, рядок стану, скелетон переходу.
- **Оголошення (еталон)** — Ф3: панель керування списком, row-card + grid, quick actions, бічна панель create/edit з канонічним футером, EmptyState.
- **Бібліотека** — Ф1: уніфіковані табы, карта тонів статусів, кнопки, тости 2.0 (Undo / STALE_CONTENT), FileDropzone у всіх станах, confirm-модалки, dirty-guard.
- **Ключові екрани** — Ф4: специфіка розділів Звіти · Збори · Інформація (двохрівневі табы) · Правління (одна панель на розділ) · Боржники.
- **Продуктивність** — Ф5: bulk-режим, duplicate + «Опублікувати одразу» з прогресом і повтором помилок, тост з Undo.

Кнопка **«Тема»** справа зверху перемикає тёмну/світлу теми.

## Зафіксовані рішення (v2)

1. Sticky-шапка при скролі схлопується в один рядок; табы завжди видимі.
2. Скелетон переходу між розділами — через `useTransition` (не `loading.tsx`).
3. Правління — **одна панель на весь розділ** (Вступ + Члени разом), без окремої панелі на члена.
4. Рядок стану дому: лічильник задач — лише якщо доступний без нових залежностей; інакше чернетки + заявки.
5. Районний колір-маркер — з `district.theme_color` (`resolveDistrictAccent`).

## Межі (з розділу 1 ТЗ — «НЕ ТРОГАТЬ»)

Бекенд і бізнес-логіка недоторкані: команди та їх payload, сервіси читання (крім нового read-only `getHouseSectionCounters`), публічна частина, RBAC-флаги, порядок виклику команд, optimistic locking. Макет — тільки презентаційний шар.
